# Downloads Sorter
Downloads Sorter is a simple tool that will sort the contents of your downloads folder by file type.
## Compatibility
- iPhone ❌
- iPad ❌
- Mac ✅
- Apple Watch ❌
- Apple Vision Pro ❌
